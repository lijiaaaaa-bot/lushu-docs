# 测算报告函件体（只寄医院）

骨架由 `FeeReportBuilder` 写成**律师函件**，不是材料清单。DeepSeek 只改连接语气。金额、条号、日期仍以骨架为准；改一个即回退。

## 正文结构

1. 标题 +「致河南省人民医院：」+ 公司名称沿革 + 合同全称 + **委托经营管理期限** + 共用计量/装表 + 停车确认表 + 测算目的
2. **测算依据**：（一）合同原条（二）测算表日期与现场确认、停车信息表/确认表
3. **停车场电费测算**：装表人员、拆除其他负荷、约30天、分区抄表与功率；不要工程师公式行，不要「（13个灯）（13个灯）」
4. **职工停车费**：2022年与2023年3月计费沿革；缺年只用一句估算
5. **测算结论** +「综上」+ 公司落款一次 + 日期一行

电费总额用精确乘积（如 `1,055,846.57`），不要照抄金标准笔误 `1,055,849.97`。
