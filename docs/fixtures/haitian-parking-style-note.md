# 测算报告金标准语气（润色用）

骨架仍由 `FeeReportBuilder` 生成：金额、条号、日期、分区、缺口不得改。
DeepSeek（钥匙串 BYOK）只改函件语气。下列锁定项必须在润色稿中**原样出现**，否则回退骨架。

## 结构（学写法，不学金标准里算错的电量）

1. 标题 +「致××：」+ 合作背景（合同期限、现场加装电表、停车确认表）
2. **测算依据**：（一）合同约定（只转写已粘贴条号）（二）事实依据
3. **停车场电费**：测量概况 → 分区实测 → 已给参数分段测算；过渡用「则」「另」
4. **职工停车费**：计费方式 → 年度表 → 缺年说明
5. **测算结论**汇总表 +「综上」+ 乙方落款

不要写「任务卡」「结构化」「本地组装」。Word 导出用 `w:tbl` 真表，不把 `|` 管道行当正文。

## 硬锁（改一个即整篇作废）

- 金额与千分位、小数位（如 `561,930.00`、`3,685,344.00`）
- 合同条号（如《合同》第九条第七款 / 第八款、第十条）
- 日历日期（如 `2018年9月1日`）
- 灯数、天数、参考电价 P、分区瓦数
- **不从零起草，不重算电费或停车费**
