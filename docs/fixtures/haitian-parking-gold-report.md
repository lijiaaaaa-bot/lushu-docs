# 金标准摘录（律师可提交测算报告）

来源：用户提供的《关于阜外华中心血管病医院地下停车场项目停车场电费及职工停车费测算的报告》.docx。
律书生成目标是**函件体测算报告**，不是材料索引。完整原件不入库；本摘录只保留结构与已公开口径。

## 结构

1. 标题 + 致河南省人民医院
2. 合作背景（合同期限、实测电表、停车确认表）
3. **测算依据**
   - 合同约定：仅用任务卡已粘贴的《合同》第九条第七款 / 第八款、第十条，不另造条号
   - 事实依据：照明测算表 + 已入库各年职工停车信息表（审计件未入库则不假装已读）
4. **停车场电费**
   - 四区实测（负一层西直梯 / 负一层住院部 / 负二层西直梯 / 负二层住院部）
   - 灯具功率 6.21 / 7.43 / 4.4 / 5.38 瓦
   - 若任务卡给出全场灯数与参考电价 P，再算跨期电费，并写明「参考电价，以双方确认为准」（金标准稿中 25.8133×24×932 写成了 577397.1264，与精确乘积差约 5 度；生成器按精确乘积，不照抄笔误）
5. **职工停车费**
   - 2022=561,930；2023=751,350；2024=865,794；2025=927,147；2026年1–7月=579,123
   - 小计 2022–2025=3,106,221；累计至 2026 年已填月份=3,685,344
   - 2018–2021 仅当任务卡写明参照已确认年份月均摊时才估算，不编行
6. **测算结论** + 乙方落款

- 年度金额必须来自 bundled xlsx「汇总」页，不得手写库存列名充数。
- 缺年、缺 P、缺灯数时：章节仍在，金额留空并说明，禁止「不代算」一句打发全章。
